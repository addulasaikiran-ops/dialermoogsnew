# Moog's Phone

A premium Android phone and contacts app with an original Liquid Glass-inspired design.

## Product status

Requirements and technical blueprint are documented in:
- [Product Requirements](docs/PRD.md)
- [Technical Blueprint](docs/TECHNICAL_BLUEPRINT.md)

The repository is currently at the planning/foundation stage. The app is intended to use Flutter + Dart for UI and Kotlin for Android Telecom, Contacts and other platform integrations.

## First test target

- Xiaomi Redmi 9 Activ
- Android 11
- 4 GB RAM

## Product principles

- Real Android default-dialer integration
- Offline core functionality
- No ads, analytics or tracking
- Android Contacts Provider integration
- Premium Liquid Glass-inspired UI, optimized for modest hardware

## Important

Call recording, floating mini-call overlays, launcher icon state changes and some call-screen behaviors depend on Android version, device manufacturer, launcher, carrier and local law. See the technical blueprint before treating these as guaranteed features.
